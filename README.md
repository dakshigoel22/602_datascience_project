# Project Title

## Classifying LLM Usage
In this project, we identify which LLM (Large Language Model) was utilized to generate the given texts. This classification helps understand the text's origin and the capabilities of different LLMs.

## Features Overview
### Lexical Features
- Word Count: The total number of words in the text.
- Unique Word Count: The number of unique words in the text.
- Average Word Length: The mean length of words used.

### Syntactic Features
- Sentence Length: Average sentence length calculated by total words divided by sentence count.
- Parts of Speech Tagging: An analysis of the frequency of different parts of speech.

### Semantic Features
- Word Embeddings: Vector representations of words to capture semantic meanings.
- Topic Modeling: Using methods like LDA to identify prevalent topics.

### Stylometric Features
- Authorship Attribution: Metrics to determine author style such as function words usage.
- Readability Scores: Assessment based on formulas like Flesch-Kincaid to gauge text complexity.

### Readability Features
- Flesch Reading Ease: Score indicating how easy the text is to read.
- Gunning Fog Index: Measures the complexity based on sentence length and word complexity.

## Key Visualization Findings
- **Feature Distributions Across Authors**: Visualizations showcasing how different authors use lexical and syntactic features.
- **Correlation Patterns**: Analysis of how features correlate with each other, indicating relationships.
- **Model Performance Insights**: Insights derived from visualizations that show how well different models perform against the datasets.

## Conclusion
This project enables comprehensive insights into text generation by LLMs and showcases significant findings from feature analysis and model evaluations.
