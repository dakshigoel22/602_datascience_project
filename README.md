# 🧠 LLM Fingerprinting: Identifying the Author of Text Using Linguistic Features

## 📌 Overview

This project explores whether we can identify the true author of a piece of text — whether written by a human or generated by a Large Language Model (LLM) — using linguistic and stylometric features.

Different LLMs exhibit subtle but measurable stylistic patterns, or **“fingerprints.”** By extracting lexical, syntactic, semantic, and structural features, we frame authorship identification as a **multiclass classification problem**.

---

## 🎯 Research Objective

Given a piece of text, can we correctly determine whether it was written by a human or by one of several LLMs?

---

## 📊 Dataset

- **Total Samples:** 8000  
- **Authors (8 Classes):**
  - 7 LLMs
  - 1 Human class
- **Prompts:** 1000 unique prompts
- **Domains:**
  - News (Reuters-style)
  - Wikipedia-style
  - Essays

### Dataset Columns

| Column Name       | Description |
|------------------|------------|
| `author`         | Name of model or Human |
| `prompt`         | Original prompt |
| `text`           | Generated or human-written text |
| `label`          | Encoded class label |
| `word_count`     | Total words in text |
| `sentence_count` | Total sentences |
| `char_length`    | Character length |

---

## 🔬 Methodology

### 1️⃣ Feature Extraction

Since machine learning models cannot directly interpret raw text, we extract structured features:

- Lexical features (word count, vocabulary richness)
- Syntactic features (sentence length variance)
- Stylometric indicators
- Readability metrics
- Structural properties

These features form the independent variables for classification.

---

### 2️⃣ Problem Formulation

- **Task Type:** Multiclass Classification  
- **Independent Variables:** Extracted linguistic features  
- **Dependent Variable:** Author label  
- **Confounding Variable:** Prompt content  

---

### 3️⃣ Model Development

- Data preprocessing
- Feature scaling
- Train/test split
- Deep Neural Network (DeepNN) classifier
- Evaluation using accuracy and confusion matrix

---

## 📈 Results

- **~82% classification accuracy**
- Strong differentiation between human and AI-generated text
- Observable clustering of stylistic traits among different LLM families

These findings support the hypothesis that LLMs exhibit identifiable stylistic signatures.

---

## 💡 Key Insights

- GPT-style models show consistent grammatical structure and structured transitions.
- Human writing exhibits greater stylistic variance.
- Prompt complexity influences classification and acts as a confounder.
